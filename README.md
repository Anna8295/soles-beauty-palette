# Solea — The Golden Hour Palette

**[See it live](https://Anna8295.github.io/soles-beauty-palette/)**

Solea is a fictional luxury makeup palette — five pressed shades of afternoon
light and a hand-cut duo brush, folded into one case. This site tells its
story as you scroll: the case opens frame by frame, settles into a flat
studio shot, and each pan can be selected to read its own story in a
slide-in detail panel.

## Run it

```bash
npm install
npm run dev
```
